# A08 测试设计人工修正

## 目标

按冻结需求、G01 审批结论与 N24 测试策略，产出可执行的 Test Case IR 与覆盖矩阵。

## 背景

范围与策略已冻结，进入测试设计；本卡由 A08 Agent 执行，输入来自 C2 已批准的范围与策略。 本卡为修正轮，绑定上一版输入参数包与校验结论。

## 范围

包含：
- Test Case IR 设计（含中英文 locale 分支）
- 覆盖矩阵与 Oracle 期望值

不包含：
- 修改冻结需求/技术方案
- 修改业务代码、提交或发布

## 输入材料

- 输入参数包（附件：`a08-input.json`）
- 冻结需求快照与 G01 结论
- N24 测试策略

## 验收

- 产出 a08-test-design-ir Artifact 并入库
- 通过 N04 校验，覆盖缺口由 A09 审查确认
