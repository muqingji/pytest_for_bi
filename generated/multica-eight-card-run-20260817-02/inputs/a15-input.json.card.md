# A15 契约自动化生成

## 目标

生成接口契约自动化候选，保护 DTO 与接口兼容性。

## 背景

契约层需要独立保护；A15 基于冻结契约生成契约校验与兼容性测试，经 A18-CT 复核、N05 检查与 G03 审核后放行。

## 范围

包含：
- 生成契约校验与兼容性测试
- 绑定契约版本、断言与数据依赖
- 产出自动化 Manifest 与 pytest 候选文件

不包含：
- 修改服务契约或业务仓库
- 代签人工审核 Gate

## 输入材料

- 输入参数包（附件：`a15-input.json`）
- C4 执行计划与 Test Case IR
- 冻结 OpenAPI 与契约快照

## 验收

- 产出 a15-contract-automation-generation 并入库
- 契约版本与断言明确，兼容性预期可审核
