## 目标

根据已批准的 G01 口径确定测试风险级别、必测层次和后续审核门禁。

## 背景

本需求同时影响错误码、多语文案、动态/多关联判定、统计图和拼表入口，需要按风险选择测试层次。

## 范围

包含：
- 基于 A06 高/中风险发现计算风险分数。
- 确定 backend、contract、e2e 必测层次。
- 确定 Case 和自动化审核门禁。

不包含：
- 不设计具体 Case，不执行测试，不修改业务仓库。

## 输入材料

- G01 已批准的人工决策
- A06 需求与实现对齐结果
- 风险策略 `risk-policy/1.0`

## 产出

- 风险级别：`critical`
- 风险分数：`20`
- 必测层次：`backend` / `contract` / `e2e`
- 后续人工门禁：Case 设计审核、自动化审核

## 验收

- G01 决策哈希与 N24 输出绑定。
- 三个必测层次不能在 A08 中丢失。
- 未授予生产发布权限。

## 需要你做什么

- 无。该节点已根据 G01 自动完成，下一节点为 A08 测试设计。
