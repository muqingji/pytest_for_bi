# 自定义字段（下拉/枚举）注意事项

- `custom_field_*` 若为下拉/单选/多选类型，其值必须是**候选项文案本身**（如制作等级为 `S/A/B/C/D`），**不能传数字序号或选项下标**（传 `2` 而非 `A` 会被 TAPD 静默存为脏值 `2`，界面显示也是 `2`）。
- 设置这类字段前，先用 `story/bug/tcase custom-fields workspaceid=XXX` 查询字段的合法候选项，再传入其中之一（**区分大小写**）。
- CLI 在 `add`/`update` 时会自动校验 `custom_field_*` 是否落在候选项内，不匹配会直接报错阻止提交；确需跳过校验可加 `skip-cf-check=1`。
- 校验为 fail-open：拉取字段配置失败或字段无候选项时会放行，因此**回读结果时仍应对照候选项再次确认**，不要仅凭 API 返回原值就判定设置成功。
