为什么分六层

把人机交互、调度控制、模型判断、程序裁决、契约约束和事实存储拆开，才能避免“卡片被改了就算通过”或“Agent 输出直接进入主链”的灰色路径。

关键安全边界

Agent 默认 artifact-only；业务仓库只读；外部写入必须通过受审计 Adapter。缺 Schema、旧哈希、越权路径、非法工具轨迹均拒收或 blocked。
