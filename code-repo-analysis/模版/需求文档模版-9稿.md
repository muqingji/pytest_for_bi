一、背景
背景比方案更重要。通过背景说明价值收益，没价值的项目不应浪费资源。
内部平台产品最常见的收益是“降本增效”，即解决某些业务流程中的问题，通过业务流程改变 / 增加系统工具，简化、甚至完全改变某些流程和角色，降低组织成本、提升运转效率。
需要注意的是，实际流程往往存在冗余，需要看到更本质的需求，提问某些流程和需求为何存在，以减少多次中间态流程简化的成本。
在实践中，价值存在高低，需要具体问题分析。例如节省某些流程可以折算人力成本，某些流程产出物被多方需要、减少产出时间是组织整体收益，这需要 PM 有评估决断的能力。
