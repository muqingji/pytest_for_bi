| 段 | 值 | 含义 |

> 时间锚定方式：该后缀不可解码时间戳，必须用 `log_cep_dist` 按 traceId 等值 + 时间阶梯反查（见文末命令）。同族 FSW trace（如 `FSW-pxi888.1000-0msehos1j0uvfyhfmuvm`）在 `log_cep_dist` 中以精确 traceId 命中过，属可查询形态。

### 3.1 关键内部节点（EasyStat 重构流水线）

统计图查询在 `fs-bi-stat` 内走「EasyStat 重构」流水线，由 `RootFlowServiceImpl` 编排多个 FlowNode：

| 节点 | 职责 | 实测耗时（T0） |
| --- | --- | --- |
| `PreSqlContextCacheDepartmentFlowNode` | 部门上下文（RPC 缓存）预加载 | 8ms |
| `PreSqlContextCacheOrgEmployeeUserFlowNode` | 员工/用户上下文预加载 | 2ms |
| `PreSqlBaseDataMainDeptAuthDataFlowNode` | 主属部门数据权限 → 注入最终 SQL 的 `user_id IN (...)` 人员范围 | 236ms |
| `PreSqlCHBDSampleQueryFlowNode` | 预聚合采样查询（大数据量采样模式） | 188ms |
| `DataQueryPageLimitAsyncQueryFlowNode` | 真分页 SQL3 合 1 主查询（异步分页限流） | 852ms |
| `DataQueryFlowNode` | 组装并下发 ClickHouse easyStat SQL | 含在主查询 |
| `ReleaseResourcesThreadLocalNode` | ThreadLocal 资源释放 | 23ms |

> 注：`PreSqlBaseDataMainDeptAuthDataFlowNode` 是人员范围分叉的高频根因节点（见 2026-08-12 双员工报表差异报告：同权限上下文展开出 1 人 vs 约 45 人），属于统计图预聚合查询的数据权限前置注入点。

## 4. 预聚合查询 vs 实时/明细查询

| 维度 | 预聚合查询（本文 trace 所属） | 实时 / 明细查询 |
| --- | --- | --- |
| 接口 | `POST /stat/data/query` | `POST /stat/detail/data/query` |
| 请求标志 | `dataQuerySource=0`，`dbObjName=agg_data / dim_data` | 明细对象（如 `object_yroOn__c`），`is_done_query_all_detail` |
| 数据来源 | ClickHouse 预聚合表 `agg_data`（`AggregateFunction` 列，查询需 `finalizeAggregation()`）+ `dim_data` 维度映射 | 明细数据（`mt_data` / `object_data`）实时计算 |
| 结果缓存 | `bi_stat_querycache_<viewId>_<ver>_<hash>_binary`（二进制缓存，写回） | 依赖 `cacheTime` / `agg_data_time` 新鲜度判断，可全量查明细 |
| 典型耗时 | 请求 1.4~1.9s，主 CH SQL 0.85~1.09s | 数据 SQL 278ms，请求 1103ms（示例） |
| 用途 | 统计图主数据（秒级响应，量大时采样） | 穿透查看明细、对账 |

预聚合数据来源（离线链路）：

```
业务操作 → paas-op-log → MQ(RocketMQ) → paas-bi-copier 消费 → 聚合框架(agg worker) → ClickHouse
   ├─ agg_data  （预聚合指标，AggregateFunction 类型）
   ├─ dim_data  （维度映射 + 权限编码 + 员工生命状态）
   └─ mt_data / object_data（明细）
```

统计图查询只读上述预聚合结果 + 查询结果缓存，不再实时扫描业务库；因此「预聚合查询少数据」类问题通常要查同步链路（op-log → MQ → copier → agg）或权限范围注入（`PreSqlBaseDataMainDeptAuthDataFlowNode`），而不是只查 SQL。

## 7. 关键存储与表（预聚合查询视角）

| 表 | 用途 | 查询注意 |
| --- | --- | --- |

| `mt_data` / `object_data` | 明细 / 对象原始数据 | 与 agg 对账用 |

| `dt_auth_simple` | 数据权限表 | 权限过滤异常排查 |
