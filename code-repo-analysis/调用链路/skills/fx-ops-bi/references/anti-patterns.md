# BI 常见错误

- 只看 ClickHouse 查询慢就下结论"CH 性能问题"，没检查是不是同步链路延迟导致数据不全
- 看到"报表数据没更新"就直接查 CH SQL，没先确认 copier 是否正常消费
- 数据不一致时只查 CH 侧，没对比 op-log 原始数据做双向验证
- 把聚合框架的正常延迟（如聚合窗口未关闭）误判为同步故障
- 忽略租户隔离：查了别的租户的数据做对比，导致误判
- 把 6 小时组织成员缓存、2 小时 PaaS 权限点、10–30 分钟单图授权合成一种「权限要等多久」去打架
- 用过期 FAQ（部门主题暂不支持共享、BI 暂不支持对象显示字段、不落库一律不能分析）结案
- 用「目标主题暂不支持共享」否掉完成值可见；完成值走考核对象共享
- 把驾驶舱「图表级」离职配置当成个人图表配置
- 把「数据已作废或已删除」当成 CH 还在统计作废单
- 当天改订阅推送时间，当日没按新点推，直接当调度故障
- 统计图没数/无 toast 当成渲染失败或白屏，其实是没主题对象权限
- FAQ 口径互殴就升级研发；超缓存窗口仍不生效才 `需要研发处理`
