下列为 **表级租户筛选**（租户列、时间列、WHERE 模板）参考；拼 SQL 见 [filter-hint 通用规则](../../../idp-query-filter-hint.md)。

## 推荐流程

```bash
fx-ops idp --profile <profile> show tables link-mankeep --dialect postgresql -j
```
