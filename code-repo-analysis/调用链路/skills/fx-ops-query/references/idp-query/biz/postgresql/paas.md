# paas

**方言**: `postgresql` 
**说明**: 纷享销客PaaS平台核心库，包含元数据引擎、业务对象、数据权限、组织架构及开放API等平台级基础能力 
**路由**: `tenant-route`（**必填** `--tenant-id <EI>`）

下列为 **表级租户筛选**（租户列、时间列、WHERE 模板）参考；拼 SQL 见 [filter-hint 通用规则](../../../idp-query-filter-hint.md)。

执行前用 `show columns paas <name> -j` 核对 `filterHint` 与列类型。

**查询入口**: `fx-ops idp query paas`（方言规则见 ../../../idp-query-sql.md，biz 索引见 [index.md](./index.md)）

> [!WARNING]
> 下文表清单可能含 `fd_feed` 等 `fd_*` 名。工作圈 / Feed 主库权威入口是 **`biz=feed`**，见 [feed.md](./feed.md)。**不要默认 `query paas` 查工作圈动态**；`paas` 上可见的 `fd_*` 可能是镜像或残留，物理库常为 `fsdb*` 而非 `fsfeed*`。

## 推荐流程

```bash
fx-ops idp --profile <profile> show tables paas --dialect postgresql --tenant-id <EI> -j

```
