## 文件清单

| 文件 | 定位 | 什么时候用 |

| `BI数据链路报告.html` | **主交付物 · 报告正文**：九章正文 + 全部流程图 + 阅读说明，单文件、可离线打开、可打印 | 宣讲投屏；也适合直接发给同事看 |

## 使用提醒

- 本材料是**静态架构梳理**，未对生产环境执行任何查询。
- 文中阈值（如"报表查询 10 秒基线""组织成员缓存 6 小时"）来自既有知识库与实战归纳，属于**经验基线而非实时测量**；下结论请以当次环境实际数据为准。
- 表与列在不同云环境、不同租户可能存在差异，**执行 SQL 前先核对当前环境表结构**。
- 行号会随代码更新偏移，引用代码位置时**以方法名为准**。
