## 完成规则

只有在以下条件全部满足时，才能将 `状态` 设置为“完成”：

- 所有验证项都已填写，单测和回归测试通过，联调结果已记录；
- 本轮新增和修改的代码单测语句覆盖率为 100%，有覆盖率命令与结果证据；存在未覆盖行时已按人工确认门禁确认，否则不得准出；
- 本轮涉及的模块集成测试全部通过，没有失败、跳过或忽略的用例；
- 两份文档回查通过，回查脚本阻塞项为 0，建议项已修或已记录理由；
- “模块范围”一节的每个模块都已完成，四项职责/入口/落点/异常边界均有证据，未新增未登记的模块或代码位置；
- “未决项与开关”一节已填写：未决项判定有依据，确认结论已回写并重跑回查，开关默认值与回退路径明确；
- 单测覆盖的 AC 清单逐条有结论，未覆盖项写明原因；
- 未验证项已明确标注“未验证”；
- 没有人工确认阻塞项。
