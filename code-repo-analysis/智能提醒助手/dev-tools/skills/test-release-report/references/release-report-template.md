## 判定约束

- 表格中的失败、跳过、未执行和 pending 必须进入最终门禁判断，不能只在正文备注。
- “有条件准出”不是模糊通过，五项例外审批信息缺一项即判“不准出”。
- 自动化通过不能替代未执行的真实依赖、性能或容量验证；是否属于本次硬门禁按已确认范围判断。
- 历史报告只能作为背景，不能替代当前代码基线的测试结果。
