# Demo 数据

FR-001 已提供 [fr001-passive.json](fr001-passive.json)，用于复现“被动型用户有未完成任务”的决策输入和预期结果。当前 CLI 使用等价的内置 Fixture，后续切片接入统一 Fixture 加载器。

后续切片需要继续补充以下可重复场景：

1. 自驱型用户已经完成任务。
2. 被动型用户在活跃时段仍有未完成任务。
3. 用户处于免打扰时段。
4. 用户关闭 Push 权限（跳过本次提醒并记录未触达原因）。
5. 连续多日未打开 App。
6. 相同任务重复调度。

建议使用 JSON 或代码内固定 fixture，确保 README 中的演示步骤能够稳定复现。站内提醒承接相关场景属 P1，不在本期数据集中构造。
