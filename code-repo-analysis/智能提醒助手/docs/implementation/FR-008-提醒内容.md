## 决策与阻塞项

- 未解决事项：快照读取与渲染器接入发送链路随 FR-004 的发送前二次校验落地；`SNOOZE` 入口的实际点击链路与用量计数随 FR-007；真实渠道长度限制与 Deep Link 格式属生产接入核验。
- 需要人工确认：无。7 项契约缺口已由用户逐项确认为 1-A 至 7-A。
- 人工确认结果：渲染只做生成与校验、快照由调用方传入；`EstimatedMinutes` 改可选指针、`0` 为合法值；补 `push_title_max_len`/`push_body_max_len` 与「只截正文尾部」；payload 增加 `Actions` 并按排程类型区分入口；文案不落库、取证走渠道请求与事件；白名单只允许两个模板变量；渲染失败用内部错误码 `CONTENT_INVALID` 且不重试。
- 已知限制：`TemplateRenderer` 已实现并通过单测/集成测试，但 `run()` 装配在 FR-004 提供最新任务快照前仍使用 FR-005 的占位渲染器，避免在无快照时产出文案；本文件与 `AI_USAGE.md` 已记录该顺序。
